# v1.0.4 · 跨聊天更自然 + 多文件启动器

> 适配 **鲸鲸 4.1.2**。安装后请完全退出启动器（托盘右键退出）再打开。

## 修复

- 跨聊天操作不再要求严格句式，以下都能识别：
  - `那你在群里发一个：最喜欢亲爱的了`
  - `记得在奥林匹斯神人聚集地里发：今晚八点开会`
  - `在「测试群」里发：大家好`
  - `给「测试群」发一条：大家记得带伞`
- 只说「群里」时，如果只有一个群就自动选它；多个群会列出群名让你选。
- 只有「发哈，现在发」这类催促、没有内容的句子，会先问你要发什么，不会乱发。
- 「把这张图片发群里给群友看看」当前只支持文字队列；不会把图片当成文字发出去。

## 启动器

- 改用**多文件构建**（exe + DLL），不再使用被 Defender 误报的单文件自解压版；
- 启动器左侧恢复 **「补丁 / 图片」** 两栏；
- 安装器会复制整套文件；已通过 Defender 扫描（no threats）。

## 安装

1. 先装鲸鲸 **4.1.2**；
2. 下载 ZIP 解压，双击 `install.cmd`；
3. 完全退出启动器再打开；左侧出现「补丁」栏；
4. 管理页：<http://127.0.0.1:8787/patch/>。
