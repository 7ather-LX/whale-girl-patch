# v1.0.2 · 适配鲸鲸 4.1.0（可选桌面快捷方式）

> [!IMPORTANT]
> **这是补丁，不是独立软件，单独下载不能运行。**
> 必须先安装 **鲸鲸 / Whale Girl**：<https://github.com/Banan1cee/whale_girl>
> 当前适配：**4.1.0**（最新版）。

## 这个版本做了什么

- 启动器「补丁」页适配 **鲸鲸 4.1.0**；
- 安装器新增**是否创建桌面快捷方式**的选项（安装 / 更新时都会询问）；
- 产品说明和安装器里都写清楚：**没有快捷方式时怎么更新**；
- 其他功能不变：跨聊天记忆、B 站/网页/小黑盒链接阅读、视频画面、安全策略。

## 安装 / 更新（3 步）

1. 从 <https://github.com/Banan1cee/whale_girl> 安装鲸鲸 **4.1.0**，确认能正常启动、登录微信；
2. 下载本 Release 的 `whale-girl-patch-v1.0.2.zip`，解压，双击 `install.cmd`：
   - 自动找鲸鲸目录；找不到会弹窗让你选包含 `server.js` 的文件夹；
   - 最后会问 `Create desktop shortcuts ...? [Y/n]`；
     - `Y`：桌面出现「鲸鲸补丁-安装或更新」和「鲸鲸补丁-控制台」；
     - `n`：不创建，按下面「没有快捷方式怎么更新」操作；
3. **完全退出启动器**（托盘右键退出）再打开 → 点「启动」→ 左侧最后一项「补丁」。

> 只点启动器里的「重启」通常只重启内核，不会加载新的启动器文件。

## 没有快捷方式怎么更新

1. 打开 <https://github.com/7ather-LX/whale-girl-patch/releases/latest>；
2. 下载最新的 `whale-girl-patch-vX.Y.Z.zip`；
3. 解压到任意固定目录（例如 `D:\WhaleGirlPatch`）；
4. 双击解压目录里的 `install.cmd`；
5. 完全退出鲸鲸启动器，再打开 → 点「启动」。

补丁配置、聊天记忆、共享组都在 `鲸鲸目录\data\` 里，更新不会丢。

> 快捷方式指向你解压补丁的文件夹；如果删了那个文件夹，快捷方式会失效，
> 重新下载 ZIP 解压并运行 `install.cmd` 即可。

## 使用说明

打开启动器「补丁」或 <http://127.0.0.1:8787/patch/>：

- **跨聊天记忆**：点「把所有群聊放进一组」→ 群聊互通（推荐，不碰私聊）；
  或新建共享组，逐个勾选群聊 / 私聊，选择「摘要 + 原话 / 只看摘要 / 只看原话」；
- **链接阅读**：总开关控制是否读群友链接；「视频画面」控制是否看 B 站封面/故事板；
- **试读一个链接**：填 URL 点「读取」，确认模型能看到内容；
- 保存后下一轮聊天生效，不用重启。

## 已知限制

- 鲸鲸以管理员权限运行时，部分机器上 Edge 无头模式返回空页面；补丁会明确说「没读到正文」，不会编造。
- B 站只读公开信息，不读字幕、不下载完整视频；需要登录/风控的站点可能只拿到标题。
- 启动器「补丁」页只对**匹配的本体版本**构建；本体升级后如果还没有新构建，
  安装器会跳过启动器，网页控制台仍然可用。
