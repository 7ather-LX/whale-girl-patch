# v1.0.5 · 修复群重复识别与自然语句

> 适配 **鲸鲸 4.1.2**。安装后请完全退出启动器（托盘右键退出）再打开。

## 修复

- **同一个群被识别成两个群**：聊天记录里的群 ID 是 `wechat:g:...`，联系人缓存是 `...@chatroom`；
  现在统一成裸 wxid 再去重，`奥林匹斯神人聚集地` 只会算一个群。
- 更自然的说法也能触发跨聊天操作：
  - `那你在群里发一个：最喜欢亲爱的了`
  - `奥林匹斯神人聚集地发一下：今晚开会`
  - `发到群里：大家好`
  - `在「测试群」里发：内容`
- 只有「发哈，现在发」这类没有内容的催促，会先问你要发什么，不会乱发。
- 普通聊天（如「发现了一个好玩的」）不会被误判成跨聊天命令。
- 增加 `[cross-chat]` 日志：识别、找不到群、没有内容都会留下记录，方便排查。

## 启动器

- 多文件构建（exe + DLL），Defender 扫描 no threats；
- 左侧 **「补丁 / 图片」** 两栏。

## 安装

1. 先装鲸鲸 **4.1.2**；
2. 下载 ZIP 解压，双击 `install.cmd`；
3. 完全退出启动器再打开；
4. 管理页：<http://127.0.0.1:8787/patch/>。

## 已知限制

- 只支持**文字**跨聊天发送；「把这张图片发群里」暂不支持。
- 目标群必须在聊天记录或联系人缓存里；完全没出现过的群先打开说句话。
