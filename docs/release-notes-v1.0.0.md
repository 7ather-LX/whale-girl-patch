# v1.0.0 · 跨聊天记忆 + 链接阅读补丁

> [!IMPORTANT]
> **这是补丁，不是独立软件，单独下载不能运行。**
> 必须先安装 **鲸鲸 / Whale Girl 4.0.x**：<https://github.com/Banan1cee/whale_girl>
> 补丁不自带模型、微信自动化或 API Key，只给已安装的鲸鲸加两个能力。

## 这个版本做了什么

- **跨聊天记忆**：把指定群 / 私聊放进同一个「共享组」，组内可以互相看到会话摘要和相关原话；
  支持「全部群聊自动」「全部私聊自动」「手动勾选」三种范围；只读不复制，可随时关闭。
- **链接阅读**：B 站标题 / UP 主 / 简介 / 标签 / 高赞评论 + 封面 / 视频故事板画面；
  小黑盒、微博、知乎等 SPA 页面用本机 Edge/Chrome 无头渲染；普通网页抽正文。
- **安全策略**：内网 / 本机 / 云元数据地址拦截，账号密码 URL、异常端口拦截，域名黑白名单，DNS 钉扎。
- **管理页**：启动器左侧新增 **「补丁」** 一栏（仅适配 4.0.8.2），也可用
  `http://127.0.0.1:8787/patch/`；可配置共享组、试读链接、预览共享记忆。

## 安装（3 步）

1. 从 <https://github.com/Banan1cee/whale_girl> 安装鲸鲸 4.0.x（当前补丁适配 **4.0.8.2**），确认能正常启动、登录微信；
2. 下载本 Release 的 `whale-girl-patch-v1.0.0.zip`，解压，双击 `install.cmd`
   （安装器会自动找鲸鲸目录；找不到会弹窗让你选包含 `server.js` 的文件夹）；
3. **完全退出启动器**（托盘右键退出）再打开——左侧会多一栏「补丁」；
   也可以直接打开 <http://127.0.0.1:8787/patch/>。

详细图文教程：仓库里的 `docs/tutorial.md`（安装、配置、常见问题、卸载）。

## 使用说明

打开启动器左侧 **「补丁」**（或浏览器打开 <http://127.0.0.1:8787/patch/>）：

1. **跨聊天记忆**
   - 点「把所有群聊放进一组」→ 群聊之间互通（推荐，不碰私聊）；
   - 想精确选择：新建共享组 → 勾选群聊 / 私聊 → 选择「摘要 + 原话 / 只看摘要 / 只看原话」→ 保存；
   - 「预览共享记忆」可以看这一轮她实际能看到什么；
   - 私聊组默认停用，确认隐私风险后再启用。
2. **链接阅读**
   - 总开关控制是否读群友发的链接；
   - 「视频画面」开关控制是否把 B 站封面 / 故事板交给看图模型；
   - 可以按域名加白名单 / 黑名单；
   - 「试读一个链接」能直接看到模型收到的文字。
3. 保存后下一轮聊天生效，不用重启；改端口、换本体版本后重新运行 `install.cmd`。

## 更新

- 鲸鲸本体更新后，重新运行一次 `install.cmd`：恢复 `server.js` 挂钩和「补丁」页，
  配置与聊天记忆不丢；
- 补丁新版本同样下载新 ZIP、解压、双击 `install.cmd`；
- 如果新本体还没有对应的启动器构建，安装器会跳过启动器，网页控制台仍然可用。
  详见仓库 `docs/updates.md`。

## 已知限制

- 鲸鲸以管理员权限运行时，部分机器上 Edge 无头模式返回空页面；补丁会明确说「没读到正文」，不会编造。
- B 站只读公开信息，不读字幕、不下载完整视频。
- 需要登录 / 风控的站点可能只拿到标题。
