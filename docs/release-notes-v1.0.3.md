# v1.0.3 · 跨聊天操作 + 适配鲸鲸 4.1.2

> 本补丁适配 **鲸鲸 4.1.2**，安装后请完全退出启动器再打开。

## 新增：跨聊天操作

以前补丁只能让不同聊天「看到」彼此的记忆，主人在私聊里让鲸鲸去群里发消息，
模型可能会答应，但实际不会操作。

v1.0.3 加了真正的主动发送：

```text
在「测试群」里发：今晚八点开会
给「测试群」发一条：大家记得带伞
```

- 主人在**私聊**里说，鲸鲸把消息排进本体自带的主动发送队列；
- 桥接轮询到任务后发到指定群，不需要切窗口；
- 目标群从已有聊天 / 联系人缓存里按群名匹配，重名会提示；
- 只允许主人触发；优先绑定 wxid，没配有效 wxid 时按主人昵称兜底；
- 管理页新增「跨聊天操作」开关和每小时条数限制。

## 适配鲸鲸 4.1.2

- 启动器重新编译到 4.1.2，带「补丁 / 图片」两栏；
- 安装器按 4.1.2 校验启动器版本，不再因为版本号不匹配跳过页面；
- 自动识别 `F:\deep seek girl\WhaleGirl` 这类带空格 / 中文的自定义目录。

## 安装

1. 先装鲸鲸 **4.1.2**：<https://github.com/Banan1cee/whale_girl/releases/latest>
2. 下载本 Release 的 ZIP，解压，双击 `install.cmd`；
3. 完全退出启动器（托盘右键退出），重新打开；
4. 点「启动」→ 左侧「补丁」。

## 安全说明

之前的**单文件** `WhaleLauncher.exe` 被 Windows Defender 的 ML 规则误报为
`Trojan:Win32/Bearfoos.B!ml`。现在改为**多文件构建**（exe + DLL，不再自解压），
并对发布目录跑了 Defender 扫描，结果 **no threats**。
如果系统仍报警，请让 Defender 隔离/删除，不要关闭防护或加白名单；
补丁服务端和浏览器管理页不依赖启动器。

## 已知限制

- 目标群必须已经在聊天记录或联系人缓存里；完全没出现过的群先打开说句话。
- 跨聊天发送走本体的主动发送队列，桥接必须在线。
- 只适配鲸鲸 **4.1.2**；基础软件更新后重跑安装器。
