# v1.0.7 · 适配鲸鲸 4.1.8

> 适配 **鲸鲸 4.1.8**。兼容性更新。

## 更新

- 4.1.8 的聊天/记忆钩子仍兼容：
  - `Store.buildContext`
  - `Gateway.handleInbound`
  - `routes.createRouter`
  - `app.createRuntime`
  - `links.describeLink`
- 启动器换成 4.1.8 三栏版：
  - **补丁 / 图片 / 生理**；
  - Defender 扫描无威胁。
- 安装器基础版本提示改为 4.1.8。

## 安装

1. 先装鲸鲸 4.1.8；
2. 下载 ZIP 解压，双击 `install.cmd`；
3. 完全退出鲸鲸再打开；
4. 左侧「补丁」栏 / 私聊测试跨聊天指令。

`data/`、`config.json`、共享记忆配置和聊天记录不会被覆盖。
